# NeXium macOS Intel

Исследовательский перенос открытого [NeXium](https://github.com/nexium-emu/nexium) для **нативных Intel Mac (x86_64)**. Приоритет — локальная проверка Nintendo Switch homebrew / собственных NRO для проектов ремейков.

- **Статус:** подготовка переноса. Работающий эмулятор для macOS не подтверждён.
- **Первая цель:** повторяемая сборка на `macos-15-intel`, затем запуск NRO и проверка графики, ввода и звука.
- **Apple Silicon:** вторичный этап, не входит в текущий CI.
- **Без приватных игровых данных:** прошивки, ключи Nintendo и игровые образы не размещаются в репозитории.

Разработку ведём в отдельных ветках и Draft PR. Исходный код NeXium не копируем в этот стартовый репозиторий: скрипты скачивают фиксированную ревизию официального открытого проекта и применяют ограниченные исправления. После первой компилируемой версии можно обсудить интеграцию изменений через fork upstream.

Проект NeXium распространяется по MIT: [исходный код и лицензия](https://github.com/nexium-emu/nexium/blob/main/LICENSE).
